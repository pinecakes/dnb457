# dnb457
Dots and Boxes, a two player CLI game!

### Rules:
- Both players will be presented with a grid of dots, 6 across and 5 down. Each column will be labeled A-F, and each row 1-5.
- Players will take turns entering a pair of grid coordinates in the format {letter}{number}, ie: C2 D2. This will form a line between those grid points.
- If upon forming a line, a fully enclosed square is formed, it will then be marked as belonging to the player who placed that line.
- Each square that belongs to a player counts as 1 point.
- Once every single square belongs to a player, the game ends. The player with the most points wins! If both players have 10 points, it is a tie!
